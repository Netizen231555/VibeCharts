# Участие в разработке

Спасибо за интерес. Перед изменениями откройте issue с описанием задачи или ошибки.

## Правила

- Нулевые зависимости, только Canvas 2D и DOM; сеть не используется.
- Отсутствующее значение показывается явно: ноль и выдуманные данные не подставляются. Ошибка и пустой результат — разные состояния.
- Примеры и тестовые данные только синтетические.
- Не упоминайте сторонние продукты и их торговые марки в коде, комментариях и документации, не описывайте решения как «как у X» и не переносите чужой код, палитры и тексты.
- Изменение поведения сопровождается обновлением `docs/contract.md` или контракта модуля и записью в `CHANGELOG.md`.
- Комментарии объясняют причину, а не пересказывают код. Мёртвый код и устаревшие обёртки удаляются вместе с изменением.

## Проверка

```sh
for f in $(git ls-files '*.js' '*.mjs'); do node --check "$f"; done
npm test                                 # постоянные тесты контрактов (node --test)
node examples/terminal/serve.mjs 8340   # и откройте examples/ в браузере
```

Затронутый пользовательский путь проверьте в браузере, включая клавиатуру и узкий экран.

## Коммиты

Одно осмысленное изменение на коммит; сообщение объясняет, что изменилось и зачем. История не переписывается.
