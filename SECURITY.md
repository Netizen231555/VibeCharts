# Сообщение об уязвимости

Не открывайте публичный issue. Используйте «Report a vulnerability» на вкладке Security репозитория (private vulnerability reporting).

Укажите версию, шаги воспроизведения и затронутый модуль. Не прикладывайте реальные учётные данные и данные пользователей.

Поддерживается последняя версия из ветки `main`.
