# Примеры

Все данные синтетические; в примерах они помечены как демонстрационные, кроме `gallery/` (страницы для снимков). Сеть не используется. Все примеры, кроме `gallery/`, переключаются между английским (по умолчанию) и русским: переключатель в шапке или `?lang=ru`; общий помощник — `shared/i18n.js`.

| Папка | Что показывает |
|---|---|
| `terminal/` | Терминал: все 29 инструментов рисования слева (пять групп), индикаторы, окно настроек по центру (цвета тёмной и светлой темы, свечи, объём, индикаторы, стиль выбранных фигур и новых фигур; живое применение, сохранение в `localStorage`, экспорт и импорт JSON), выбор из списков инструментов, алерты по уровню цены (кнопка «Алерт», затем клик по графику; линию можно перетащить; срабатывают на эмуляции потока), поток, запоминание окна по времени при смене инструмента и интервала |
| `showcase/` | Десять компоновок шкал и панелей |
| `layouts/` | Раскладки интерфейса: по умолчанию, `compact`, своя часть, токены |
| `parts/` | Свои части интерфейса, собранные только на публичном контроллере: все инструменты рисования в попапе и в `<select>` вместо встроенной рейки; руководство — `docs/parts.md` |
| `history/` | Подгрузка старой истории страницами (`datafeed.loadMore()` при приближении к левому краю) и запоминание окна по времени при смене инструмента или интервала |
| `gallery/` | Страница фиксированного размера для снимка README (английский интерфейс): график `#hero` 1280×720 с полным интерфейсом; `window.__galleryReady` становится `true`, когда он нарисован |
| `index.html`, `main.ts`, `timeline.ts`, `versioned-feed.ts` | Статичная история и версионированный поток (TypeScript, запускается через Vite) |

Запуск из корня пакета:

```sh
node examples/terminal/serve.mjs 8340
# http://127.0.0.1:8340/examples/terminal/
# http://127.0.0.1:8340/examples/showcase/
# http://127.0.0.1:8340/examples/layouts/
# http://127.0.0.1:8340/examples/gallery/
```

Сервер слушает только loopback и не кэширует ответы.
