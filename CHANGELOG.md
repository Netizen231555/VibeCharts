# Changelog

## 0.1.0 — unreleased

- New `interaction.setDrawingStyle()` / `getDrawingStyle()`: the style new drawings start with, applied to the construction preview and the committed drawing (properties a type lacks are skipped; one undo step). `drawings.applyStyle` is typed for a partial style on one or several drawings.
- The terminal's settings are a centred dialog (not modal: the chart behind it stays usable) with tabs for the chart (background, text, grid, crosshair, axes, font size), candles (body, border, wick colours, linked or separate, visibility, presets), series (volume, line and area, last-price line), indicators (every output colour) and drawings (style of the selected drawings with a live preview and one undo step, and the default style of new ones). The dark and the light theme are edited separately, changes apply live without a rebuild and are kept in localStorage, and the settings can be exported and imported as JSON (invalid files are rejected with the offending field named).
- The hidden accessible data table (caption, column headers, direction and "not provided" texts) follows the chart `locale` like the other host texts; it was English only. New `table.*` keys in `src/dom/messages.js`.
- Examples: `terminal`, `showcase`, `layouts`, `parts`, `history` and the showcase app in `App/` have a language switch, English by default and Russian second (`?lang=ru` or the switch in the header; the choice is stored and the page reloads); the shared helper is `examples/shared/i18n.js`. Instrument names and interval labels in `terminal/data.js` carry both languages. The terminal's left bar offers all 29 drawing tools in five groups (from the library's own tool model, armed through the headless controller) and a click anywhere on a watchlist row opens the ticker.
- The `measure` tool draws a box between its two anchors (green for a rise, red for a fall) with a horizontal and a vertical arrow and a badge with the price change, its percentage, the bar count and the elapsed time (the time only when both anchors sit on bars). Geometry can carry a `tone` (`up`/`down`) and labels a `box`/`lines` badge; the old three plain text lines are gone.
- A click (not a drag) on empty plot clears the drawing selection, so the last selected drawing no longer stays highlighted. A `pointerleave` reported while the pointer is still over the chart (as releasing pointer capture can) no longer hides the crosshair until the next move; a real leave, including onto an overlay control, still does.
- Dragging a drawing moves the drawing itself: it follows the pointer instead of a dashed ghost that jumped to the final place on release. The document and undo stack still change once, on release (`drawings.setDragPreview`).
- The crosshair sits on the snapped position (nearest bar and its nearest O/H/L/C price) whenever snapping is effective, with or without a drawing tool armed, as the pointer moves and when a modifier is pressed or released. A drawing tool is given that same point from the first pointer-down on (`begin`, `move` and `end`), so an anchor is no longer placed at the raw pointer first and moved to the snapped spot afterwards.
- The snap modifier accepts a list and defaults to `['alt', 'meta']`, so Cmd works on a Mac as well as Option.
- Drawing snapping: the built-in magnet toggle now actually snaps (it switches to strong mode with the bar-centre magnet; before it set weak mode without a source and nothing snapped), a persistent snapping mode without `sourceId` resolves the pane's primary price series like the modifier does, and line and area series snap to their `value`. Pressing or releasing the snap modifier with a still pointer redraws the construction preview.
- A resize of the chart container (and a change of device pixel ratio) redraws in the same frame instead of on the next one, which painted one blank frame per resize and showed up as a flash while a page settled.
- New `chartUI.icons` option replaces built-in icons by name with SVG path data (`controller.icons` and `createIcon(doc, name, { icons })` for custom parts); an unknown name or invalid data fails with `INVALID_UI_OPTION`. New token `--chart-ui-rail-size` sets the drawing rail's button size.
- New `examples/history/`: older history in pages (`datafeed.loadMore()` called from `visibleRangeChange` near the left edge) and a time window kept when the instrument or interval changes; the terminal example keeps the window across instruments and intervals too, and sets its working window before the first frame instead of two frames later (which painted every bar squeezed first).
- A drawing rail along the top or bottom uses full-size buttons; the compact two-column button size applies only to the vertical grid.
- New `examples/parts/` with two copyable parts built only on the public controller, a popup holding all drawing tools and a native `<select>`, a runnable page that switches between them and the built-in rail, and the guide `docs/parts.md`.
- Tool controls in the model carry `groupLabel`, the localized name of their group (`toolGroup.*` messages in English and Russian), so custom markup can label groups without its own text.
- The chart UI has a sixth region, `end` (right of the chart). The drawing rail may stand in `start`, `end`, `top`, `bottom` or `overlay`, the top bar in `top` or `bottom`, the navigation cluster in `overlay`, `top` or `bottom`; the rail's orientation follows its region (rows along the top and bottom scroll sideways; in `overlay` it floats over the plot at the start edge; tooltips open away from the attached edge) and top-bar menus open upward when there is no room below. Existing layouts and the `full`/`compact` presets render as before. `examples/layouts` shows the right, bottom and floating placements.
- The headless interface layer is a documented, typed contract: `UiController`, `UiModel`, `UiControl`, `UiActionResult`, `UiActionAccess`, `UiStateKey` and `UiReadKey` replace the loose `Record<string, unknown>` types, and `CHART_TYPES`, `INDICATORS`, `createToolbarModel`, `activateControl` and `findControl` are typed precisely. Controller `get`, `snapshot`, `model` and `actions` now throw `UI_DESTROYED` after `destroy()` (they threw `CHART_DESTROYED` or nothing before). The controller works with no built-in part mounted; see "Headless interface layer" in `docs/contract.md`.
- The status line keeps its state text whole and, when narrower than 460px, shows only the DEMO tag (full wording in the tooltip).
- The keyboard focus ring of the chart host is drawn inside the container (negative outline offset) instead of spilling onto neighbouring panels.
- Alert level lines show their status in the chart language (`alerts.status.*`) instead of the raw engine token.
- Time-axis labels reserve space for the UTC indicator and skip labels that would overlap or extend beyond the plot.
- Price labels stay at their actual scale coordinates without leader lines; overlapping ticks are omitted and conflicting series values remain available in the accessible overflow list.
- Crosshair readout uses a compact instrument/interval and value legend; time and price appear on their axes while slot identity and trading date remain in the accessible table.
- The hidden price-label overflow list is styled as part of the package theme (surface, border, compact typography, list spacing) and its toggle label matches the package language instead of fixed English.
- The crosshair legend has no background plate: it renders directly over the plot with a background-coloured text halo that keeps the glyphs readable over candles and grid lines.
- In the `compact` UI preset the settings trigger sits in the lower plot corner and appears on pointer hover, keyboard focus or an open menu; top-bar controls are visually denser while touch targets stay at their platform size.
- Floating on-chart chrome (navigation cluster, compact settings trigger) uses the new translucent `--chart-ui-overlay-bg` token, so the plot shows through; dropdown menus stay opaque for readability.
- Crosshair lines use the current theme; unavailable future timestamps no longer display a bar offset as a date. Nested legend entries are indented.
- Floating controls appear when their chart is active, with touch and keyboard access; top-bar controls use a lighter idle appearance.
- The x axis now belongs to the pane: independent derived views (Renko, Kagi, Point & Figure) get their own element axis per pane and can sit next to candle panes in one chart; navigation, crosshair and axis follow the pane under the pointer. A view sharing a pane with visible series is reported as a conflict instead of being drawn on a foreign axis. Drawing selection changes trigger redraw, selected drawings are highlighted, and Delete removes the selection. See CONTRACT.md, "X axis per pane".
- Initial index-timeline chart package, optional chart features and local synthetic examples.
- The API is pre-1.0 and may change incompatibly in a minor release. Pin the version; check this log and migration instructions for each upgrade.
- Publication, packaged-consumer checks, browser support, accessibility and performance gates are not implied by this entry.
- Added `examples/terminal/`, a dependency-free terminal example on the public API (toolbars, drawing tools, indicators and panes, OHLC legend, watchlist, range bar, themes, PNG export) with a deterministic synthetic data generator. No library behaviour or defaults changed.
- Chart destruction closes chart-owned subscriptions, frames, observers, pointer capture and DOM resources; retained chart-managed handles reject further operations. Shared host alert engines and arbitrary host-owned module APIs remain independently owned.
- Resize retains the logical range through zero size and updates the canvas buffer for the current DPR. Cleanup failures are reported after remaining resources have been released.
- Added host-supplied session boundary styling and independent index-axis colors; Heikin Ashi now retains the source candle body, border and wick settings.
- Crosshair events now reach chart subscribers, respect pane offsets and expose free history-edge offsets; last-value labels can be toggled independently, avoid overlap and retain overflow in a keyboard-accessible list.
- Pointer navigation now respects pane-local scale coordinates, scale-side layout changes and nonlinear/inverted price scales; touch contacts follow tool/object/axis priority and release together on cancellation. Index-axis reset uses the captured initial step.
- Accessible tables show numeric-series values and explicit units and follow data and chart time-zone changes; an empty synthetic screener dataset is reported as empty rather than as a load error. Screener loading and empty states are status regions, resize handles have visible keyboard focus, and table labels and chart legends use contrasting colors.
- Keyboard overrides reject browser-reserved chords and alias conflicts atomically; chart shortcuts respect interactive descendants and nested chart ownership. Accessible buttons provide pan, zoom and bar navigation without shortcuts.
- Stochastic supports large valid lookback windows without exceeding JavaScript argument-count limits.
- Published typed configuration and result shapes for trusted series, drawing and indicator extensions.
- Workspace synchronization uses the chart's fractional-anchor crosshair API when available, including explicitly mapped future coordinates.
- Clicking a marker cluster's nested count opens the intended cluster without intercepting an individual marker selection.
- Workspace comparisons render explicit mapped data and primary percentages, retain source visibility through restore, and expose accessible base and removal controls. Workspace snapshots omit comparison values; consumers must supply fresh points with `setComparisonData` after restoration. Percentage comparisons on one chart now share a base slot, and marker clustering distance is measured in CSS pixels.
- Comparison mappings retain not-yet-loaded source IDs as gaps; removing a primary source leaves its comparison usable and restorable. Marker-capable adapters must expose pixel coordinates through `indexScale().indexToCoordinate()`.
- Workspace snapshots are now version 2: viewport endpoints use bar identities and fractional offsets; version 1 snapshots are rejected. Restore reports loading/unresolved anchors until matching data arrives. Theme documents now use visual chart-option patches, and indicator-template adapters must provide transactional replacement and isolated validation factories.
- Indicator and drawing templates preserve real chart state and validate before applying; drawing templates retain target favorites, saved styles and repeat mode. `Chart.exportPng()` captures the currently displayed canvas, and preference storage no longer emits a storage-success event.
- Empty bar observations interrupt comparison continuity for alerts associated with that stream; the first subsequent value initializes quietly instead of firing a false crossing.
- Backend alert adapters must declare idempotency support and scope. Mutation request IDs use secure UUIDs or a host-provided unique generator, and delivery-status changes notify subscribers without duplicating events.
- Alert observation keys now include chart identity and full indicator identity; hosts must construct them with `sourceKey()` instead of literal strings. A disconnected shared feed interrupts only its own scoped stream.
- Drawing alert thresholds include fractional anchor offsets, validate resolved geometry before saving and require observed bar identities to resolve against the host timeline.
- Local alerts now revise their saved geometry with drawing edits, initialize quietly after revision, and become unavailable on drawing deletion until the same geometry returns.
- Changing a series' visibility emits `datachange` with `kind: 'seriesVisibility'`, and only when the value actually changes, so workspace trees and other subscribers can follow it.
- Price labels append an explicit `priceUnit`, render `priceUnit: 'percent'` as `%`, and do not repeat a currency identical to the unit.
- Restoring a chart applies the default last-value label visibility without turning it into an explicit series override, so `series.options()` keeps reporting only explicit settings.
- Added a fail-closed packaged-consumer release diagnostic; browser, accessibility, license, vulnerability and performance evidence remains required before publication.
- Replay snapshots use version 3 with SHA-256 source/configuration identities, speed and simulation definitions. Bar replay requires the host's full slot order; integrated replay clears the linked chart to the empty prefix and leaves live alert state untouched.
- The synthetic browser benchmark now supports visible Chromium, runs update and camera workloads with its drawing/indicator profile attached, samples in-cycle heap peaks and refuses to pool incompatible runs. Sampled peaks remain lower bounds and no release budget is implied.
- Benchmark reports now pool each heap delta and residual separately in bytes, preserve the sampled-peak limitation, and record browser diagnostic API availability.
- Alert levels share selection with the workspace editor, which requires the captured revision and reports validation and uncertain backend outcomes. Series and indicator lifecycle changes invalidate affected local alert sources.
- Drawing construction and drag previews use the committed geometry; multi-selection dragging, pane-scoped hit testing and input-draft preservation are supported.
- Chart restoration rolls back attempted module state and defers chart and integrated drawing notifications. Direct timeline changes and history removal validate module contributions before committing.
- Theme switching updates the canvas and crosshair; unset color overrides inherit the selected theme and can be reset with `null`.
  Previously saved snapshots containing explicit dark colors retain those overrides; set the relevant color fields to `null` to inherit the current theme.
- Indicator computation failures are reported separately from missing values, suspend dependent local alerts and clear after recovery. Rolling means retain small contributions when large values leave a window.
- The UI starts with an unknown data status instead of claiming an unstarted load. A host-owned shared alert session survives chart destruction; the host marks a source unavailable when the source itself stops.
- Custom indicator and extension registration expose typed definitions, instance handles and lifecycle events; custom indicator inputs reject invalid numbers before computation.
- Extension state documents use version 2 and reject imports from a different instrument, interval, source or view; version 1 documents require explicit migration.
- Benchmark defaults now select the full workload, ten-second continuous measurements and twenty memory cycles; diagnostic overrides remain explicitly non-release evidence.
- Explicit seconds and offset-bearing ISO time adapters validate dates, UTC offsets and millisecond precision; timeline inputs remain Unix milliseconds.
- Indicator outputs track source metadata and units; metadata changes and scale compatibility are validated atomically.
- The standalone static example reports its successfully loaded synthetic data to the chart UI instead of leaving its status unknown.
- Custom index-axis labels no longer display an unverified UTC designation; UTC remains shown for actual UTC-formatted timestamps.
- History-removal previews expire when series or affected objects change; local drawing alerts pause when an anchor is removed and reinitialize after it returns.
- Diagnostic history removal on Darwin arm64, Node 24.22.2: five fresh charts with 100,000 slots and numeric points, preview plus removal of 50,000 slots, took 56.1, 43.5, 41.1, 34.4 and 31.2 ms. No approved budget or comparable baseline; this is not a release benchmark.
- Derived views are calculated before data commits; failures preserve source and derived state. Diagnostic Renko correction on Darwin arm64, Node 24.22.2, 10,000 OHLC slots and five updates took 2.2, 2.3, 1.1, 1.2 and 1.3 ms. No approved budget or comparable baseline.
- Autoscaling excludes hidden series and refreshes on visibility changes. Diagnostic camera workload on Darwin arm64, Node 24.22.2: 1,000 range changes across 100,000 numeric points with 200 visible slots took 15.1 ms; no approved budget or comparable baseline.
- Derived elements track their input lineage and parameters; corrections cannot silently retarget an existing selection. IDs restore across recreated views when complete source context is available; otherwise they remain view-scoped. Heikin Ashi avoids intermediate sum overflow, and non-advancing Point & Figure cells fail explicitly.
- Diagnostic Renko correction with stable SHA-256 lineage on Darwin arm64, Node 24.22.2, 10,000 OHLC slots and five updates took 5.0, 5.2, 5.3, 5.1 and 5.0 ms; an earlier per-bar digest implementation took 40.2 ms on its second update. The pre-lineage baseline was 1.1–2.3 ms. Heikin Ashi over 10,000 slots took 135.8 ms to create and 80.1 ms to correct, improved from 189.6 and 105.7 ms by combining lineage digests. The cache retains only the latest computation to avoid growth across updates. No approved budgets or release benchmark.
- Added opt-in calendar time ticks, crosshair time formatting, last-price lines and direction colors, label countdowns, price-axis spacing and autoscale margins, and independent overlay scales. Existing defaults remain unchanged.
- Added the optional `vibecharts/styles.css` stylesheet and migrated the synthetic terminal and screener charts to overlay volume. Context menus are constrained to the viewport when the stylesheet is used.
- Wheel and Alt+wheel zoom now respond proportionally to small trackpad deltas instead of applying a full zoom step per event.
- The default wheel zoom factor is 1.15 per full step; `wheel.factor` remains configurable.
- Changed the default dark-theme rise/fall colors (candles, wicks, baseline), the default drawing color and the example and screener palettes and font stacks to project-specific values. Hosts that rely on the previous defaults must set them through series and theme options.
- **Breaking:** `attachUI` and the `ui` option of `attachChartFeatures` are removed, together with `applyTheme` and `controlReachable`. The interface is now built by `createChartUI` (option `chartUI`) from parts — `topBar`, `drawingRail`, `navCluster`, `settingsMenu`, `statusLine`, `dataTable` — placed in regions through a validated `layout` (presets `full` and `compact`, host parts, `without`, `ui.replacePart`, `ui.setLayout`). The accessible table is hidden by default. Added the optional `vibecharts/ui.css` stylesheet with `--chart-ui-*` tokens, an own icon set (`createIcon`), `controller.actions()` and the example `examples/layouts/`.

- The interaction crosshair lines are dashed (4px dash, 4px gap) instead of solid.
- Added the `watermark` chart option (`visible`, `text`, `color`, `fontSize`): bold text centred behind the series of the first pane, theme text colour at alpha 0.07 by default; empty text draws nothing.
- Candlestick/bar points accept optional `buyVolume` and `sellVolume` (finite, `>= 0`); added the built-in `delta` indicator (`buyVolume - sellVolume`, histogram, theme rise/fall colours by default); histogram series and indicator styles accept `upColor`/`downColor` for sign colouring; histogram autoscale now includes zero.
- Added rebindable chart hotkeys `f` (follow realtime), `r` (fit content), `l` (linear/log price scale) next to Home auto-scale; Shift pins the second point (drawing tool) or the dragged handle of `segment`/`ray`/`line`/`arrow`/`measure` to the other anchor price; alert level lines are draggable by mouse/pen and commit through the alert engine update, snapping back with a reported error when rejected.
- Added hold-a-modifier drawing snap: `setDrawingSnap({ modifier })` (`'alt'` default, `'ctrl'`, `'meta'` or `null`; `'shift'` is rejected). While held during drawing-tool placement/preview and handle drag, snap is strong (O/H/L/C of the source, defaulting to the pane's first visible candlestick/bar series) with the bar-centre magnet regardless of the persistent mode; tool `move`/`end` meta now carries `{ shiftKey, altKey, ctrlKey, metaKey }`. The held modifier suppresses the context menu and Alt-wheel zoom during drawing; on macOS Ctrl+click is a context-menu gesture, so Alt is the default.
- **Breaking:** the settings menu «⋯» now lists «Тёмная тема», «Следование последнему бару», «Таблица данных», the new checkable «Логарифмическая шкала» (`interaction.toggleLogScale`, new `interaction.getPriceScaleMode`; disabled with a reason on a percent scale) and «Привязка рисунков» (`setDrawingSnap` mode `free` ↔ `weak`), then «Панели…» and «Настройки рисунков…» (the former coordinate-construction dialog). Keyboard crosshair, pan, price zoom and previous/next bar items are removed from the default menu and shown only with the new `createChartUI` option `accessibleActions: true` (boolean); their actions and keyboard bindings are unchanged. The context menu depends on the target (plot, price axis, pane) and omits unavailable items instead of showing them disabled with a reason; a target without items opens no menu and Shift+F10 announces «Нет доступных действий». `buildMenuItems` items no longer carry `enabled`/`reason`, `createContextMenu` no longer has `ACTION_DISABLED`, the `refused` event or `lastRefusal()`, and the `.chart-menu-reason` / disabled-item styles are removed.
- **Breaking:** exported drawing documents use the format id `vibecharts/drawings` (previously a project-internal id); documents with the old id are rejected as `invalid-format`. The package is released under the Apache License 2.0.
- Documentation layout: the contract moved from `CONTRACT.md` to `docs/contract.md` (with a `docs/README.md` index); added `CONTRIBUTING.md`, `SECURITY.md`, `NOTICE`, `.editorconfig`, `examples/README.md` and GitHub issue and pull request templates.
- README is now in English (`README.md`) with a Russian version (`README.ru.md`), screenshots, installation from GitHub and an AI-assistance note in the status section.
- Chart UI (`src/ui`) strings are translated: labels, aria-labels, announcements and errors follow the chart `locale` (any `ru` locale → Russian, otherwise English) via `src/ui/messages.js`; `createToolbarModel`/`activateControl` take `locale`, `directionLabel(open, close, locale)`, the default `title`/`demoLabel` are localized, `controller.t`/`controller.locale()` added.
- Interaction, core, integration and DOM-host strings are translated: instructions, aria-labels, menu labels, announcements, readout field names and errors follow the chart `locale` (any `ru` locale → Russian, otherwise English) via `messages.js` in each module; `DEFAULT_INSTRUCTIONS` is now `defaultInstructions(locale)`, `ABSENT`/`ABSENT_TEXT` are `absentText(locale)`, `keyboard.labels` and `actionLabel` take a locale, and `createStatusModel`, `createDerivedViewAccessibility`, `createPaneLayout`, `createDrawingTool`, `buildMenuItems`, `createContextMenu`, `buildTableModel` accept `locale`.
- Fixed regression channel and anchored VWAP never rendering in the integrated drawing store: series values are now mapped to {index, value}.
- Added `examples/gallery/`: a fixed-size English page for the README screenshot (`#hero`, 1280×720, with the full chart UI whose chart type and indicator menus are wired, volume, SMA/EMA, RSI, volume delta, drawings and a fixed crosshair). It reuses the terminal example's data generator and sets `window.__galleryReady` once the chart has rendered.
- Drawing texts no longer show float noise: the integrated drawing store now gives the geometry adapter `formatPrice` (the axis-label formatting with the series `priceStep`) and `formatPriceDelta`; the price label and the measure «price» difference use them, the measure «intervals» value is rounded to two decimals, and the fallback without an adapter hook rounds to 12 significant digits.
- **Breaking:** the drawing rail offers all 29 drawing tools in groups (lines, channels and Fibonacci, shapes, annotations, analysis) with an own icon each; a tool id is now the library tool name (`segment`, `horizontalLevel`, … replace the UI ids `trendLine`/`horizontalLine`, and `TOOL_ALIASES` and the icon aliases are removed), `DRAWING_TOOLS` entries carry `group`, chart-type icons are renamed `chartType.<id>`. Past 12 tools the rail is a two-column grid with group separators and scrolls vertically; the controller supplies default props for `text`/`callout`/`flag`, `regressionChannel` and `anchoredVwap`, and announces an error when a tool cannot be armed.
